# 음악 추천 품질 개선 (2026-11-23)

같은 30개 음악 사례, 같은 심사 모델(gemini-3.6-flash). 심사는 사람보다 음악을 15~20%p 후하게 보므로 절대값보다 실행 사이의 차이로 읽어요(eval/review/findings.md).

| 실행 | 프롬프트 | 모델 | 잘 맞음 | 응답 p50 | 서로 다른 곡 | 스토어 못 찾음 |
|---|---|---|---|---|---|---|
| q-base-r1/r2 | 운영(이전) | 3.5-flash-lite | 81% / 80% | 2.8s / 2.9s | 105 / 103 | 3 / 5 |
| q-new-r1/r2 | 소리 먼저·제목 낚시 금지·원곡 아티스트·예비 4곡 | 3.5-flash-lite | 91% / 84% | 4.1s / 4.3s | 99 / 91 | 2 / 0 |
| q-new2-r1/r2 | 위 + "히트곡 습관 금지" | 3.5-flash-lite | 80% / 83% | 3.8s / 4.0s | 104 / 94 | - |
| q-flash-r1 | q-new와 같음 | 3.6-flash | 89% | 7.3s | 106 | 5 |

결정: q-new 프롬프트, 모델은 그대로(lite). "히트곡 습관 금지"는 맞음 비율과 제외 지킴이 나빠져 뺐어요. 3.6-flash는 맞음이 비슷하고 응답이 두 배 가까이 느려요.
남은 약점: 같은 히트곡(Dynamite, Blinding Lights 등)이 여러 요청에 반복돼요. 스토어 조회는 분당 한도 때문에 평가에서 절반쯤 '조회 실패'라 실존 비율은 하한선이에요.
